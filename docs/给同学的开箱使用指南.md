# 研途打卡开箱使用指南（给同学）

这是一个可以直接在手机和电脑上使用的科研打卡小应用，不需要安装开发环境。

## 第一步：打开链接

- 点击我发你的链接，或者扫描我发你的二维码。
- 首次打开可能会稍慢几秒，属于正常现象。

## 第二步：安装到手机

- iPhone（Safari）：打开链接 -> 点下方“分享” -> 选“添加到主屏幕”。
- Android（Chrome）：打开链接 -> 点右上角菜单 -> 选“安装应用”或“添加到主屏幕”。

安装后可以像普通 App 一样从桌面打开。

## 第三步：安装到电脑

- Windows（Chrome/Edge）：打开链接后，在地址栏右侧点击“安装应用”。
- macOS（Chrome）：打开链接后，在地址栏右侧点击“安装应用”。

安装后可从桌面或应用列表直接打开。

## 常见问题

- 为什么手机和电脑数据不一样？
  - 这是本地版应用，每台设备的数据单独保存在本机浏览器，不会自动同步。
- 为什么没收到系统通知？
  - 请在浏览器里允许通知权限，再到应用设置页确认提醒开关。
- 第一次打开有点慢怎么办？
  - 等待资源缓存完成后，后续打开会更快。
