# 科研打卡站（本地 PWA）

轻量、无后端的科研打卡系统，支持：
- 开始/结束科研打卡（同一时刻只允许一个进行中会话）
- 上午/下午/晚上时段管理
- 每日/每周统计与最近 7 天趋势
- 每日/每周目标进度和连续天数（streak）
- 刷手机中断计数
- 温和提醒（默认 09:00 / 14:00 / 20:00，可在设置页修改）
- 收尾提醒（上午/下午固定时间提醒，可“立即结束 / 延后15分钟 / 忽略本次”）
- Bark 手机提醒（iPhone，需在设置页填 Bark Device Key）
- 每周科研周报卡片
- 离线可用与桌面安装（manifest + service worker）

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://localhost:5173`

## 质量检查

```bash
npm run lint
npm run test:run
npm run build
```

## 5 分钟发布到 Vercel

1. 把项目代码推到 GitHub 仓库。
2. 打开 Vercel，点击 `Add New... -> Project`，导入该仓库。
3. Vercel 会自动识别为 Vite 项目，默认构建命令和输出目录可直接使用。
4. 点击 `Deploy`，等待发布完成后得到线上链接（如 `https://xxx.vercel.app`）。
5. 可绑定自定义域名，方便同学记忆和访问。

发布后建议先自行验证一次：打开链接、进入设置页、测试“复制分享链接”和“安装此应用/手动安装步骤”。

## 如何分享给同学（手机 + 电脑）

1. 在应用设置页找到“分享与安装”，复制分享链接或让同学扫码二维码。
2. 手机端安装：
   - iPhone（Safari）：打开链接 -> 分享 -> 添加到主屏幕
   - Android（Chrome）：打开链接 -> 菜单 -> 安装应用/添加到主屏幕
3. 电脑端安装：
   - Windows（Chrome/Edge）：地址栏右侧点击“安装应用”
   - macOS（Chrome）：地址栏点击“安装应用”

说明：本项目数据保存在浏览器 `IndexedDB`，各设备数据独立，不会自动同步。

## 数据存储

- 会话、设置、提醒去重状态均保存在浏览器 `IndexedDB`。
- 单用户本地使用，不依赖后端和云同步。

## Bark 手机提醒

- 在设置页启用“手机提醒（Bark）”，填写 `Bark Device Key` 后保存。
- 可点击“发送测试到手机”立即验证推送。
- 本提醒由前端本地定时器触发，仅在 app 打开运行时生效。
